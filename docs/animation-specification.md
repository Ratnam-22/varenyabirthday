# Project Varenya

# Animation Specification

Version: 1.0

---

# Animation Philosophy

Animations are not decorations.

Animations tell the story.

Every movement should have meaning.

Every object should feel alive.

The website should feel like an animated movie rather than a collection of UI transitions.

Never animate simply because something can move.

Movement should communicate emotion.

---

# Animation Principles

All animations should follow these rules:

• Smooth

• Elegant

• Organic

• Physical

• Predictable

• Cinematic

Never:

Flash

Shake aggressively

Bounce excessively

Spin randomly

Use cheap effects.

---

# Motion Language

Objects have weight.

Objects have momentum.

Objects have anticipation.

Objects have follow-through.

Objects never instantly stop.

Objects never instantly appear.

Objects never instantly disappear.

Everything transforms.

Never cut.

Never instantly fade.

# Camera Rules

Camera never teleports.

Camera always moves.

Camera movement should feel like a drone.

Small acceleration.

Small deceleration.

Very soft curves.

Never sudden movement.

---

# Butterfly Behaviour

Random flight.

Never repeat obvious paths.

Occasionally land on flowers.

Fly away when touched.

Return after several seconds.

---

# Firefly Behaviour

Random movement.

Glow pulses naturally.

Gather near cursor.

Disperse slowly.

Never move in straight lines.

---

# Flower Behaviour

Idle sway.

Bloom when clicked.

Release petals.

Petals become particles.

---

# Lantern Behaviour

Float upward slowly.

Affected by wind.

Brightness slowly changes.

Disappear into stars.

---

# Star Behaviour

Twinkle randomly.

Occasional shooting stars.

Constellation animation.

Parallax movement.

---

# Final Rule

The user should never consciously notice the animations.

They should simply feel that the world is alive.

The technology should disappear.

The emotion should remain.
