# Project Varenya

# Design System

Version: 1.0

---

# 1. Design Philosophy

The entire website should feel luxurious, magical, cinematic, and handcrafted.

Every visual element should contribute to the emotional storytelling.

The user should never feel overwhelmed by unnecessary UI.

The experience should feel immersive rather than decorative.

The interface should almost disappear, allowing the story to become the primary focus.

---

# 4. Color Philosophy

Avoid bright rainbow colors.

Avoid harsh gradients.

Avoid excessive saturation.

Colors should feel expensive.

Lighting should create emotion.

Dark backgrounds should make glowing elements stand out naturally.

# 25. Responsive Philosophy

Immersive cinematic experience.

Tablet

Mobile

Touch-first experience.

---

# 26. Performance Rules

Always maintain smooth animation.

Reduce particle count on mobile.

Reduce post-processing on weaker devices.

Lazy load heavy scenes.

Optimize textures.

Compress models.

---

# 27. Accessibility

Support Reduced Motion.

Keyboard Navigation.

Semantic HTML.

Readable Typography.

Good Contrast.

Visible Focus States.

---

# 28. Final Design Rule

Every pixel should have purpose.

Every animation should tell part of the story.

Every transition should feel intentional.

The user should leave remembering the experience rather than the technology.
